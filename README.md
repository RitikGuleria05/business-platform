\# Business Platform



A full-stack business platform built with ASP.NET Core 8, MySQL, and a modern frontend.



\## 🚀 Project Overview



This project is a full-stack web application designed to provide business-related functionality through a RESTful API and web-based frontend.



The backend is built using ASP.NET Core 8 and connects to a MySQL database.



The frontend is currently under active development.
